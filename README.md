# CartoonLens
A real-time computer vision project that transforms webcam footage into a cartoon-style video feed using image processing techniques.

This project was created as part of my learning journey in Python and computer vision to explore real-time frame processing, edge detection, and visual effects using OpenCV.

The system captures live camera input and applies cartoon-like filtering effects frame by frame to create a stylized live camera experience.

 # Note

This project was built for educational and practice purposes while learning computer vision and real-time image processing concepts.

# Features:
Real-time webcam filtering,

Cartoon-style visual effects,

Edge detection and smoothing,

Live frame processing,

Lightweight and interactive interface.
